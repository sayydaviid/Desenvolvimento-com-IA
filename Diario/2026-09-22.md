# Diario - Aula 03: Tres Skills para o PR

**Data:** 2026-09-22
**Exercicio:** Criar tres skills, cada uma cobrindo um momento diferente do PR.

---

## Skills Criadas

### 1. pr-planner (Interativa)

- **Modo:** Interativa
- **Intencao (intent):** planning
- **Celula da matriz:** Interativa / Antes do codigo
- **O que faz:** Planeja o PR antes de qualquer codigo ser escrito. A skill pergunta ao usuario sobre escopo, arquivos afetados e criterio de pronto (definition of done), e gera um plano estruturado.
- **O que declara no metadata:**
  - mode: interactive
  - intent: planning
  - matrix_cell: "Interativa / Antes do codigo"
- **Arquivo:** .agents/skills/pr-planner/SKILL.md

### 2. pr-closer (Reativa)

- **Modo:** Reativa
- **Intencao (intent):** closing
- **Celula da matriz:** Reativa / Apos o codigo
- **O que faz:** Fecha o PR. Disparada pelo usuario quando o codigo esta pronto. Roda os testes, atualiza a documentacao e abre o PR automaticamente, sem perguntar nada.
- **O que declara no metadata:**
  - mode: reactive
  - intent: closing
  - matrix_cell: "Reativa / Apos o codigo"
- **Arquivo:** .agents/skills/pr-closer/SKILL.md

### 3. pr-watcher (Autonoma)

- **Modo:** Autonoma
- **Intencao (intent):** monitoring
- **Celula da matriz:** Autonoma / CI falhou
- **O que faz:** Vigiar o PR. Dispara sozinha quando o CI falha (via hook ou GitHub Action) e comenta no PR a causa provavel da falha.
- **O que declara no metadata:**
  - mode: autonomous
  - intent: monitoring
  - matrix_cell: "Autonoma / CI falhou"
- **Arquivo:** .agents/skills/pr-watcher/SKILL.md

## Observacoes

- Cada skill foi criada na pasta .agents/skills/ seguindo o padrao do Antigravity Customization System.
- O frontmatter YAML de cada SKILL.md inclui campos personalizados (mode, intent, matrix_cell) alem dos campos obrigatorios (name, description).
- As skills cobrem os tres momentos do ciclo de vida de um PR: planejamento, fechamento e monitoramento.
