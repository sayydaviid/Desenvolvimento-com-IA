## O que construir para melhorar os três requisitos mais fracos

Os requisitos de backend e RAG ficaram com **0**. Há um empate entre três requisitos com **1**; escolhi **LLMs e agentes** como terceiro porque é central para a vaga da DataEX.

**1. Backend e APIs (0 → 1, depois 2).** Eu começaria estudando como funciona uma API HTTP e montaria um backend pequeno com Python e FastAPI, com rotas para cadastrar e consultar informações. Para comprovar prática com agente, colocaria o código no GitHub, documentaria as rotas e faria requisições reais de teste. Assim, depois do aprendizado inicial, poderia justificar uma nota 2.

**2. RAG e banco vetorial (0 → 1, depois 2).** Criaria um sistema que recebe arquivos do próprio projeto, transforma o conteúdo em embeddings, guarda esses vetores e recupera trechos para responder perguntas usando um LLM. Registraria exemplos de perguntas, respostas e referências recuperadas, para mostrar que a resposta realmente usa os documentos.

**3. LLMs e agentes de IA (1 → 2).** Construiria um agente de atendimento simples com LangGraph ou outro framework semelhante. Ele receberia a dúvida, decidiria quando chamar uma ferramenta (por exemplo, consultar uma API) e devolveria uma resposta. Eu faria isso com um agente de programação e guardaria o código, os prompts e testes de execução no repositório.
